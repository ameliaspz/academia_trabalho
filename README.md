# Site de Academia IRON HOUSE

Projeto acadêmico desenvolvido para praticar HTML, CSS e JAVASCRIPT.

## Sobre o projeto

O site apresenta uma academia chamada IRON HOUSE, com informações sobre as modalidades, informações sobre a academia e a equipe. O site também contém uma página de login para alunos e uma página de login para professores e funcionários.
O projeto busca unir um visual simples e organizado com as principais informações e funcionalidades de um site de academia e tem uma finalidade acadêmica de praticar codificação.

## Tecnologias utilizadas

- HTML5
- CSS3
- JAVASCRIPT

## Funcionalidades

- Página inicial
- Tópicos de navegação
- Apresentação das modalidades e acompanhamento
- Seção sobre a academia
- Página de login para alunos
- Página de login para professores e funcionários
